# AI Critique

Overall, Claude performed an amazing job of generating JMeter test plans for performance testing scenarios in HW05, as well as providing detailed analyses of the .jtl logs. The Thread Group settings for the scenarios were realistic for EShop, and the assertions inside the requests correctly focused on performance metrics instead of functional validation. This is important because it allowed the plans to reflect the actual goal of these scenarios, which is identifying bottlenecks and stress behavior rather than just checking whether a response succeeded. The timers between the requests proposed by the AI and the AI's rationales those timing decisions were reasonable and justifiable In addition, the suggested thresholds were aligned with the results read from the test logs and the optimization ideas were mostly feasible for the SUT. However, the AI still made several mistakes that required manual review. In one case, it suggested a request body that omitted an essential value; in another, it missed an important assertion for an important field. While these issues would not affect the final performance result, they were significant enough to show that AI-generated answers still need human double-checks before being accepted. After collaborating with the AI in this homework, I think that I can apply some prompting techniques to obtain better output from AI.
