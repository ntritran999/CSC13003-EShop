### **4. Conclusion — When should AI be used (or not)?**

Overall, the AI model (Claude) demonstrated strong capabilities in automated API test generation, effectively synthesizing test suites across domain partitions, state transitions, security constraints, and schema validation. The majority of the generated test cases were valid, featuring well-structured payloads, deterministic assertions, and insightful edge cases. Nonetheless, quality degradation was observed at higher volumes of generation, occasionally yielding out-of-scope scenarios, ambiguous expected outcomes, or hallucinations of undocumented requirements. To mitigate these failure modes in future iterations, fine-grained prompting strategies—including explicit boundary constraints and negative prompting against requirement hallucinations—should be integrated into the audit and generation pipeline.
