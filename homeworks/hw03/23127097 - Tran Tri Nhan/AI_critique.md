# AI Critique

Overall, the AI tool (Claude) had proven to be excellent at following instructions. By giving the AI enough context about the descriptions of the EMS website and the requirements for the interface aspect and the screens, it generated a GUI checklist that correctly covered requested areas. However, despite the attempt to provide clear guidance, the AI still missed some items or details while creating the GUI checklist. Because the AI had to follow the grounding about usability heuristic and interface design(Nielsen's, Norman's, Shneiderman's) and other commands when constructing the checklist, it simply got overwhelmed and chose the safest options, and gave common GUI items for the checklist instead of covering all the possible interactions. While generating the GUI checklist, the AI read the descriptions of the IA requirements and got biased, so it created items for what were listed inside the parenthesis only. Moreover, the prompt did not include the description about the UI implementation of the website, so Claude avoided the riskier option of designing items for specific UI element and instead just provided generic items based on the given requirements. After working with the AI on this homework, I had learned value lessons. The most important lesson is to always provide enough context, even if I initially thought that some of the materials would be unrelated, I have to think carefully about what context I give the AI and whether such context is sufficient.
