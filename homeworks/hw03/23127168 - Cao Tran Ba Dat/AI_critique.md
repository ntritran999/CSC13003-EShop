# AI Critique

Overall, Claude did a fantastic job following instructions. Once we gave it enough context about the EMS website and our screen requirements, it generated a solid GUI checklist that covered all the main areas. That said, it wasn't completely thorough. Because we loaded the prompt with so many design rules and heuristics, the AI seemed to get a bit overwhelmed. It ended up playing it safe by giving us fairly generic checklist items instead of diving into specific user interactions. It also got a little too literal—focusing mostly on details inside parentheses from our requirements and skipping unmentioned UI elements entirely. Still, this was a great learning experience. It really taught me that prompt engineering isn't just about giving information, but carefully thinking through what context the AI actually needs to do the job right.
