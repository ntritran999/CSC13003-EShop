# AI Critique

During the test design process, the AI demonstrated distinct blind spots, most notably by generating incomplete user workflows and exhibiting confusion over methodological applicability. For instance, while analyzing the FR-03 (Password Reset) feature, the AI successfully identified the "Confirm Password" field as a critical input variable and correctly mapped its Equivalence Classes. However, it completely omitted the necessary physical step of entering this confirmation password within the actual test execution steps. Furthermore, when evaluating the Order Cancellation features (FR-10 and FR-Mobile), the AI showed a vulnerability to "hallucinating" test techniques. It struggled to intrinsically grasp that Boundary Value Analysis (BVA) is exclusively for continuous, ordered variables, nearly forcing BVA parameters onto discrete, categorical state machine statuses before being properly constrained.

These failures occurred because the AI operates as a localized pattern-matching engine rather than a holistic system thinker. It excels at generating structured markdown tables based on explicit prompts, but it lacks the "common sense" required to visualize a chronological user journey through a graphical interface. It understands the textbook definitions of software testing but lacks the engineering intuition to recognize when a technique is logically inapplicable to the domain.
