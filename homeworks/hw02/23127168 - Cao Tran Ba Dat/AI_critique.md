# AI Critique

</center>

Based on my work with the AI ​​in this homework assignment 2, I realized that my AI tool was making some mistakes related to missing test cases to cover all the functional requirements of the README.md file. Some of the test cases it generated were not entirely suitable for the system's operation, and importantly, some test cases involved modifying the source code (which is not feasible in domain testing). The AI's failure to detect these missing issues may be due to its incomplete functionality, and the code modifications in some of the generated test cases could stem from my prompt or documentation not specifying rules for code modification. Through this assignment, I learned the importance of carefully reviewing the accuracy and completeness of the test cases generated by the AI, avoiding the aforementioned unexecutable test cases, and selecting test cases that are appropriate for the system and avoid duplication and overlap.
