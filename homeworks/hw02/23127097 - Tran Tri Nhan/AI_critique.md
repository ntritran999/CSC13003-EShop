# AI Critique

Overall, the AI proved to be a good assistant when it came to applying domain testing and boundary value analysis to design test suites for the system under test. When providing the AI with enough materials(feature specifications inside the README file, guidlines of the courses), the AI correctly identified equivalence classes most of the time and also designed good test cases. However, there were still places where the AI made mistakes or missed key details. After reading the specifications, the AI still wrongly identified some of the equivalence classes when applying domain testing for a feature, even though within the same response it had already pointed out that some of the requirements of the feature were UI-focused only and not suitable to infer equivalence classes from. Meanwhile, with the already found equivalence classes, the AI completely missed the test objective when designing the test cases and missed the test step for the test cases of FR-01 specifications. The reason for the missing test objective and test step was because I gave the AI guidelines about desigining test cases without specifying the structure of a test case or what fields should a test case contain. The principles that I have learned after collaborating with the AI tool(ChatGPT) for this homework are: 1.Always provide the AI with relevant materials and resources, which reduces the chance of hallucination and avoid lenghty prompts; 2.Even with the files provided, be sure to always explicitly tell the AI what I want, for example, instead of prompting 'apply guidelines for this feature [feature x]', I should clearly specify which guidelines I want to apply for the AI to understand me correctly.
